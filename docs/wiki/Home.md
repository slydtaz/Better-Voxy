# Better Voxy: Help and Guides

Welcome! This is the place to find help with installing Better Voxy, adjusting its settings, and figuring out what to do when something goes wrong.

Better Voxy is a Minecraft Java Edition modpack built around Voxy's distant-terrain rendering and a selection of optimization mods.

- **Minecraft:** 26.2
- **Mod loader:** Fabric

## Need a hand?

- [Choose an issue form](https://github.com/slydtaz/Better-Voxy/issues/new/choose)
- [Browse existing issues](https://github.com/slydtaz/Better-Voxy/issues)
- [Open the source repository](https://github.com/slydtaz/Better-Voxy)

If you report a problem, include your Better Voxy version, Minecraft version, Fabric Loader version, the steps that led to the issue, and any relevant log excerpt. Remove access tokens, passwords, and private server addresses first.

One last thing: back up important worlds before running chunk pre-generation or making major configuration changes. It is much easier to restore a backup than to recover a world after something goes wrong.
