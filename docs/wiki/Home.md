## Support

- [Choose an issue form](https://github.com/slydtaz/Better-Voxy/issues/new/choose)
- [Browse existing issues](https://github.com/slydtaz/Better-Voxy/issues)
- [Source repository](https://github.com/slydtaz/Better-Voxy)

Before reporting a problem, include the Better Voxy version, Minecraft version, Fabric Loader version, reproduction steps, and relevant sanitized logs. Never share access tokens, passwords, or private server addresses.

Back up important worlds before using chunk pre-generation or making major configuration changes.
