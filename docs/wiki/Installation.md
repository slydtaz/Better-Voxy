# Installation

## Install through the Modrinth App

1. Open the Better Voxy project page on Modrinth.
2. Download the `.mrpack` file for the version you want.
3. Open the Modrinth App and choose **Import from file**.
4. Select the downloaded Better Voxy `.mrpack`.
5. Wait for the app to download the listed mods and configuration files.
6. Start the new instance.

Use the Minecraft and Fabric Loader versions shown on the project version page. The first launch can take longer while mods initialize.

## Recommended precautions

- Back up important worlds.
- Test the pack without extra mods, shaders, or resource packs first.
- Create a separate instance before experimenting with additional mods.
- Do not copy the entire client modpack into a dedicated server.

## If import fails

Try downloading the `.mrpack` again and updating the Modrinth App. If the error persists, report it using the [crash or serious issue form](https://github.com/slydtaz/Better-Voxy/issues/new?template=04-crash-or-serious-issue.yml). Include the error message and remove private information from logs.
