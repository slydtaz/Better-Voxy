# Installation

Ready to play? The steps below cover importing the modpack through the Modrinth App.

## Install through the Modrinth App

1. Open the Better Voxy project page on Modrinth.
2. Download the `.mrpack` file for the version you want to use.
3. Open the Modrinth App and choose **Import from file**.
4. Select the Better Voxy `.mrpack` you downloaded.
5. Let the app download the listed mods and configuration files. This may take a little while.
6. Start the new instance once the installation finishes.

Use the Minecraft and Fabric Loader versions listed on that release's page. The first launch may take longer than usual while the mods initialize.

## Before you start

- Back up any worlds you care about.
- Try the pack as-is before adding your own mods, shaders, or resource packs. That makes it much easier to track down conflicts.
- Make a separate instance for experiments so your main setup stays intact.
- Do not copy the entire client modpack into a dedicated server. Client mods and server requirements are not interchangeable.

## Having trouble importing?

Try downloading the `.mrpack` again and make sure the Modrinth App is up to date. If it still fails, [report a crash or serious issue](https://github.com/slydtaz/Better-Voxy/issues/new?template=04-crash-or-serious-issue.yml). Include the error message and remove private information from any logs you share.
