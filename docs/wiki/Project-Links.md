## About the documentation pages

The Markdown files in `docs/wiki/` are documentation pages kept alongside the source repository, so they can be edited and reviewed like any other file.

If you want to publish them in GitHub's separate Wiki area, you will need to create or edit the pages there. The native Wiki uses its own Git repository; GitHub only makes that repository available to clone after the Wiki has been initialized with a page.
