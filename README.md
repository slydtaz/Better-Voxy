# Better Voxy

Support, issue templates, and contributor guidance for the Better Voxy Minecraft modpack.

## Get help or report a problem

Choose the form that best matches your request:

- [Suggest an additional mod](https://github.com/slydtaz/Better-Voxy/issues/new/choose)
- [Suggest a configuration change](https://github.com/slydtaz/Better-Voxy/issues/new/choose)
- [Report a minor or unknown bug](https://github.com/slydtaz/Better-Voxy/issues/new/choose)
- [Report a crash or serious issue](https://github.com/slydtaz/Better-Voxy/issues/new/choose)

GitHub will show the available forms after you choose **New issue**.

## Before opening an issue

- Search existing issues to see whether the problem has already been reported.
- Include your Better Voxy version, Minecraft version, and Fabric Loader version.
- Describe what you expected to happen and what happened instead.
- For crashes, attach the crash report or a relevant excerpt/link to `logs/latest.log`.
- Mention any mods you added, removed, or updated and any configuration files you changed.
- Remove access tokens, private server addresses, and other sensitive information from logs.
- Do not upload entire Minecraft folders, world saves, or mod JAR files.
