# Better Voxy

Better Voxy is a Minecraft Java Edition modpack built around Voxy's distant-terrain rendering, with optimization mods and settings chosen for this pack. The idea is to see more of your world and make everyday gameplay feel smoother without turning Minecraft into a completely different game.

Performance will still depend on your hardware, the world you're playing in, shaders, and your settings. There is no one-size-fits-all FPS number.

- **Minecraft:** 26.2
- **Mod loader:** Fabric

## Need help or found a problem?

If something is not working, check the troubleshooting guide first. If you still need help, choose the form that best matches the issue:

- [Suggest an additional mod](https://github.com/slydtaz/Better-Voxy/issues/new?template=01-add-mod.yml)
- [Suggest a configuration change](https://github.com/slydtaz/Better-Voxy/issues/new?template=02-settings-change.yml)
- [Report a minor or unknown bug](https://github.com/slydtaz/Better-Voxy/issues/new?template=03-bug-minor-or-unknown.yml)
- [Report a crash or serious issue](https://github.com/slydtaz/Better-Voxy/issues/new?template=04-crash-or-serious-issue.yml)
- [Browse existing issues](https://github.com/slydtaz/Better-Voxy/issues)

When reporting a problem, include your Better Voxy version, Minecraft version, Fabric Loader version, what you did before the issue appeared, and a relevant log excerpt if you have one. Please remove passwords, access tokens, and private server addresses before sharing logs.

Back up important worlds before pre-generating chunks or making major configuration changes.
